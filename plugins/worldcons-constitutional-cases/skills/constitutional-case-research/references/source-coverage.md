# Source coverage

The plugin currently searches public constitutional-case material collected from these source families:

- Germany: Bundesverfassungsgericht
- United States: Supreme Court opinions selected by the site's collection policy
- France: Conseil constitutionnel
- Spain: Tribunal Constitucional

Coverage varies by institution, year, document type, and collection status. Use `list_sources` for the live list and site URLs. Search results include only records that have completed the public publication workflow.

The plugin does not provide a complete official reporter, citator, docket system, or negative-treatment history. Absence from search results is not evidence that a decision does not exist.
